# Motorboat engine audio

The existing `MotorboatEngineAnimation` component automatically plays three layered, 3D, speed-responsive loops for the former sailboat prefab (motorboat ID `sailboat`).

Add the user-provided sound clips to this folder, using the exact resource paths:

- `slow.ogg` — motor idle / low speed
- `moderate_speed.ogg` — cruising speed
- `fast.ogg` — high speed

The supplied Unity ZIP contains mono Ogg Vorbis versions with loop seams crossfaded, suitable for Android. Unity imports them as AudioClips; no prefab rewire is necessary. Git-track the files and the .meta files generated by Unity. The sound component logs a warning for each missing clip.
