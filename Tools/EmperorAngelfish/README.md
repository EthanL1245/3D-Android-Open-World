# Emperor Angelfish integration

Stable IDs: 33 adult, 34 juvenile. Both supplied FBX and PNG assets are committed under Assets/_Game/Reef/Source; original Blender files are in ArtSources. The automatic installer generates both prefabs on opening Unity, before Play or a build. Manual rebuild: Tools > Open World > Rebuild Emperor Angelfish. Each FBX has one authored ArmatureAction swim take and the expected Bone through Bone.004 chain. Shared RedSnapperPresentation and procedural held-fish movement apply as for Titan Triggerfish.

Suncrest Beach is biome suncrest-reef (0). Worm and legacy-worm tables roll the angelfish family at 30%; the existing other fish share 70%, with triggerfish 3% each and red snapper/flounder/stingray parity preserved. Unspecified other baits have 0% angelfish chance. All other biomes have zero odds and unavailable weight ranges. Juvenile has no independent random roll.

Chosen normal catch length: 10–40 cm. Weight uses FishBase's Pomacanthus imperator Bayesian estimate W(g)=0.01738 * TL(cm)^2.88, approximately 13.18–714.47 g. This is a model estimate, not measured specimen weights. FishBase reports a 40 cm **standard-length** maximum; our conservative 40 cm **total-length gameplay ceiling** is a design choice, not a claim that these measurements are identical. Reference: https://www.fishbase.org/summary/Pomacanthus_imperator.html . Five-centimetre samples use the existing shared interpolation system. Existing hotspot/Charm bonuses can exceed the normal catch range.

The bottom 20% is interpreted in physical length: 10 + .2*(40-10) = 16 cm. ResolveSizeVariant compares final caught weight to the shared table's weight at 16 cm, after all size bonuses and pond adjustment, and stores the juvenile ID only below or at that boundary. Both IDs share size and combat curves. Difficulty .42, health 115–342, yellow swim speed 3.152 m/s match Red Snapper at equivalent size percentiles. Sell values follow its 40–300 coin range.

Target-species tournament families: Mako/Battle Scarred Mako, Blackfin/Great Barracuda, Bluefin/Giant Trevally, Roughtail/Leopard Stingray, Emperor/Juvenile Emperor Angelfish. Only normal IDs are drawn as targets. Variants retain their own catch IDs, names, biome restrictions and validation ceilings. Every member scores the same 100 points per actual kilogram without a variant score multiplier. Other independently catalogued fish remain separate targets. Client and server family maps must remain synchronized.

Validation: node Tools/EmperorAngelfish/verify_rules.mjs; node --test Server/tests/*.test.mjs. Unity Editor is required to generate/render the prefabs and visually verify animation, texture alignment and held mouth anchoring. Deploy the updated Server/runtime for authoritative tournament behavior.
